# 1C API Gateway (Node.js)

Надежный API-шлюз для интеграции 1С с внешними системами (сайты, CRM, маркетплейсы).

## 🚀 Особенности
- **Асинхронность:** Снимает нагрузку с базы 1С.
- **Надежность:** Встроенный механизм повторных попыток (retry) при сбоях сети.
- **Валидация:** Строгая проверка входящих JSON-схем.
- **Логирование:** Полное отслеживание всех запросов и ошибок.

## 🛠 Стек
- Node.js, Fastify, Axios, axios-retry

##  Запуск
1. npm install
2. node mock-1c.js
3. node gateway.js
4. node test.js

## 💼 Для заказчиков
Этот шаблон адаптируется под любой формат JSON за 1-2 часа. Гарантирует, что данные не потеряются при падении 1С или обрыве связи.
